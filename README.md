# FiribStop UZ — обновляемые индикаторы киберугроз

Страница «Ущерб от киберугроз» теперь разделяет два разных типа данных:

- Исторические денежные оценки ущерба — статичные опубликованные суммы с ссылками на источники.
- Обновляемые индикаторы — официальные записи CISA KEV об уязвимостях, которые уже используются в реальных атаках; также собираются Feodo Tracker, лента UZCERT и (при наличии API-токена) Cloudflare Radar.

График CISA KEV показывает число записей, добавленных в каталог за каждый из последних 30 дней, а не количество кибератак и не денежный ущерб. Статус «ДАННЫЕ СВЕЖИЕ» отображается только при доступном CISA KEV и снимке не старше двух часов. При ошибке источника или старом снимке страница сообщает об этом.

## Как включить обновление

1. Загрузите весь проект в GitHub и убедитесь, что файл `.github/workflows/live-stats.yml` доступен в основной ветке.
2. Откройте вкладку **Actions → Live stats → Run workflow** и запустите первое обновление. Workflow также запускается автоматически каждый час.
3. Убедитесь, что запуск завершился зелёной галочкой и в `data/live-stats.json` появились поля `cisaKev`, `generatedAt` и `cisaKev.fetchedAt`.
4. Если сайт размещён на Netlify через этот же GitHub-репозиторий, проверьте, что автоматические deploy после новых коммитов включены. Если нет — запустите новый deploy в Netlify вручную.

Cloudflare Radar требует необязательный секрет репозитория `CLOUDFLARE_RADAR_API_TOKEN`. Для CISA KEV отдельный токен не нужен. Если все источники недоступны, сборщик завершится ошибкой и не перезапишет последний корректный снимок.

Проверка скрипта локально (Node.js 20+): `node scripts/fetch-live-stats.js`.
